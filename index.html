⚙️ 설치 방법

💡 다운로드 후 설치: 아래 "앱 다운로드" 버튼을 클릭하면 APK 파일이 다운로드됩니다.
카카오톡 in-app 브라우저에서는 동작하지 않으므로 링크를 복사하여 외부 브라우저에서 실행하세요.

다운로드 후 설치 방법:

📂 다운로드 폴더 위치:
• Chrome 브라우저: '다운로드' 또는 'Download' 폴더
• Samsung Internet: 'Download' 폴더
• 기타 브라우저: 기본 다운로드 폴더
  • 1. 파일 관리자 앱을 실행합니다.
  • 2. 다운로드 폴더에서 'concert.apk' 파일을 찾습니다.
  • 3. 파일을 탭하면 설치 확인 팝업이 나타납니다.
  • 4. '설치' 버튼을 클릭합니다.
  • 5. 설치 완료 후 '열기'를 눌러 앱을 실행합니다.

설치가 안 되는 경우 (권한 설정):

  • 1. '설정' 앱 실행 → '보안' 또는 '개인정보 보호' 메뉴 선택
  • 2. '출처를 알 수 없는 앱 설치' 또는 '알 수 없는 출처' 항목을 찾습니다.
  • 3. 이 브라우저(Chrome, Samsung Internet 등)를 선택합니다.
  • 4. '이 출처 허용' 또는 '허용'을 켜줍니다.
  • 5. 다시 "앱 다운로드" 버튼을 클릭합니다.

🚨 보안 팁: 설치 완료 후에는 "출처를 알 수 없는 앱 설치" 설정을 다시 끄는 것이 안전합니다.
